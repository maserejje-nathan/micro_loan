Server requirements

  • PHP 8.3+ with extensions: bcmath, ctype, curl, dom, fileinfo, json, mbstring, openssl, pdo, tokenizer, xml
  • MySQL 8+ or MariaDB 10.6+ (recommended for production)
  • Composer 2.x and Node.js 20+
  • Apache or Nginx with public/ as the document root

Installation

1. Upload files

Upload the package to your server. Point the web root to the public directory.

2. Environment file

cp .env.example .env

Edit .env with your database credentials, APP_URL, and mail settings.

3. Install dependencies & build

composer install --no-dev --optimize-autoloader
php artisan key:generate
php artisan migrate --force
php artisan db:seed --force
php artisan storage:link
npm install
npm run build

Or run composer setup on a machine with both PHP and Node installed.

4. File permissions

Ensure storage/ and bootstrap/cache/ are writable by the web server user.

Cron & queue worker

LendFlow uses a database queue and a daily scheduler for overdue loan processing.

Cron (required)

* * * * * cd /path/to/lendflow && php artisan schedule:run >> /dev/null 2>&1

Queue worker (required)

php artisan queue:work --tries=3

Use Supervisor or systemd to keep the queue worker running in production.

Integrations

Email

Configure MAIL_* variables. Super-admin SMTP settings are available at Admin → Settings → SMTP.

SMS

Set SMS_DRIVER=log for testing or africas_talking with API credentials for live SMS.

Mobile money

Set MOBILE_MONEY_DRIVER=stub for demo disbursements, or yo with Yo! Payments credentials.

Borrower portal

Enable under Settings → Client portal for each lending organization.

Production checklist

  • APP_ENV=production and APP_DEBUG=false
  • Strong unique passwords for super admin and all demo accounts
  • HTTPS enabled; SESSION_SECURE_COOKIE=true
  • MySQL/MariaDB with regular backups
  • Queue worker and cron configured
  • SEED_DEMO_DATA=false after initial setup if you do not want demo data re-created
